# Gauntlet boon catalog

All 80 original ideas are represented by game-compatible implementations, alongside six extra boons.
The descriptions below match the current effects. Boons are unique and reset each run.

## Adaptations

Claude's existing changes remain: Hearty grants Health, Glass Cannon increases damage dealt and taken, Momentum rewards kill streaks, Meditation heals while stationary, and Kingsfoil Pouch supplies herbs.
The One Ring uses a charged opening hit instead of native invisibility. Mirror Image absorbs a hit instead of replacing enemy AI targets.
Echo Cast releases a bounded spirit burst and boon follow-ups rather than re-entering arbitrary native cast callbacks. Boomerang and Voice of Command use delayed follow-up strikes. Split Shot and Twin Souls add bounded secondary attacks rather than cloning arbitrary native skills.
Summoner's Pact and Army of the Dead use the existing ghost summon adapter instead of converting enemy AI into allied AI.
Elven Volley splashes two nearby foes rather than altering native arrow collision. Fault Line creates a short damage zone, and Heir of Isildur extends owned ghost lifetimes.
Avalanche uses a rising proc chance capped at 25%. Long Reach widens shared skill queries and custom delivery areas; skills with private native range checks retain those checks.

## Limits and lifecycle

Secondary damage does not recursively trigger Overkill or death-explosion damage. Healing, cooldown rewards and status transfer can still occur on those kills.
Boon damage requested inside a native hit callback is queued for the player tick, keeping native combat calls off each other's stacks.
The runtime tracks eight affected enemies and four queued or delayed targets. New work is skipped when these bounded pools are full.
Actor generations prevent a dead enemy's status or delayed hit from transferring to a reused actor slot.
Room transitions and run cleanup free the effect workspace, clear pending echoes, and restore transient stat overlays.
Boon ghosts keep their lifetime, owner and target in native actor state, with no separate heap registry. They share the player's four-ghost cap.
A native killing hit must retain negative HP for Overkill to observe excess damage; a native path that clamps HP to zero has no observable excess.

## Verification

Run `uv run python hacks/tools/test_gauntlet_boons.py` for ownership above bit 31, offer restrictions, unique grants, status ticks, slot reuse, duo spreading, overkill, stat overlays, cast repeats, wards and cleanup.
Use `gauntlet_run.py --boons` for emulator stress tests. Full-pool stress is separate from normal reward selection.
Manual play remains necessary to assess balance, visuals and how individual native skills interact with the adapted effects.

### Validation snapshot, 2026-10-24

The release build passed 14 emulator runs and 172 combat-room clears: twelve rooms for each of ten heroes with every boon owned, eighteen-map normal-reward probes for Aragorn, Smeagol and Saruman, and an eighteen-map all-boon probe for Ringwraith.
All reported zero failed placements, zero allocation failures, intact memory guards, and no BIOS or invalid-instruction warnings. Test ROM copies were compared with the release ROM after restoring their test configuration bytes.
The full-pool Ringwraith stress minimum was 16 bytes of heap address headroom; normal reward probes retained at least 512. More RAM-heavy additions need fresh measurements.
The host boon regressions, shared ability regressions and 91 Python tool tests passed. The progression-cheat check finished room one at level 3 with Max Level enabled, and confirmed the campaign setting still works outside a run.
These checks cover engine stability and specific effects. Manual playtesting of timing, visuals, balance and individual native skill interactions remains necessary.
