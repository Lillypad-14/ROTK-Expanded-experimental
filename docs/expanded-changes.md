# ROTK Expanded change overview

This describes the experimental expansion present in the source tree. It is not a release announcement or a promise that every feature has passed full gameplay testing. The original decompilation, toolkit and Vanilla+ patches are credited to RagingCactus and [lotr-gba-re/rotk](https://github.com/lotr-gba-re/rotk), as described in the root README.

## Current release summary

[v0.7-experimental](https://github.com/Lillypad-14/ROTK-Expanded-experimental/releases/tag/v0.7-experimental) adds Eowyn's experimental Against the Dark page-two kit. The previous boon and bug-fix pass remains included.
Gauntlet has 94 boons, including four new character choices, two tradeoffs, and two evolving boons. Some offers favor compatible choices; L on the doors screen opens the goals panel.
The gear shop supports buying and selling. Door descriptions explain rewards, modifiers, and map names.
The available pool is 28 maps; City Streets and Minas Tirith (Gates) are excluded because screen captures reproduced corrupted terrain.
Herbal Healing ranks 2 through 5 add 10% through 40% maximum HP healing per herb on top of normal healing.
See [Gauntlet](gauntlet.md), [the boon catalog](gauntlet-boons.md), and [the current bug audit](bug-audit.md) for exact behavior and testing limits.

## Other patches

[`hacks/patches.cfg`](../hacks/patches.cfg) is the default selection. The [generated patch inventory](source-inventory.md#mod-patch-inventory) lists every patch directory and whether that file selects it.

- The inherited foundation includes save-slot pages, Ranger Hollow pages, loot quality-of-life options, chapter select, fast fades and modular options/scenes. Read the [upstream user guide](romhack-user.md) for their controls and save behavior.
- Expanded also contains debug cheats, unlock controls, Twists playthrough modifiers, text overrides, item descriptions and wait-state changes. The [mod options guide](mod-options.md) lists every settings page and Twist. Inspect the patch directories for other behavior and dependencies.
- `test_arena` is available through `make test-arena`. Demo patch directories are examples and are not default gameplay features.
- Required save/RAM/startup/scene patches must remain selected as documented by the build. A patch appearing in the inventory does not establish that it can run alone.

## Recent four-hero fixes and coverage

The Sam, Smeagol, Aragorn and Saruman audit corrected omitted equipment active-skill bonuses, Sam's missed-hit secondary effects and inherited weapon requirements, stale actor references for marks/bait/curses, and shared targeting behavior. See [hero move checks](hero-move-checks.md) for the exact automated and emulator coverage.

The earlier four-hero audit ended with an interrupted emulator smoke attempt; it is historical coverage, not the latest status.
The 2026-10-25 audit subsequently completed all-hero ability sweeps, shop debugger checks, and 280 combat-room clears across all ten heroes and the 28 available maps with every boon granted. It also corrected stat-boon overlays after equipment changes, duplicate cast completion, custom sixth-slot Echo Cast eligibility, and unique equipment requirements.
See [the current bug audit](bug-audit.md) for exact coverage and limits. Normal-control encounters, complete visual behavior, multiplayer and hardware still need community testing.

## Validation and release scope

Run `make check-mod` for the original-game checks plus the selected hack's linked-content and host regression checks. Use `make check-hacks` for the combined patch selection, `make check-fx` for graphics tooling and `make check-hero-moves` for the focused kit checks. Dependencies and full commands are in [workflow](workflow.md).

The [original changelog](romhack-changelog.md) records the upstream mod's releases. The expansion overview and inventory describe repository content, which can be newer than any published BPS. Release notes should identify the source commit, selected patches, validation performed and known limitations. Distribute BPS patches rather than ROMs.

## Ringwraith second-page progression

Shadowstep opens at level 10, Command of the Nine at 11, Shadow of Mordor at 12, and Black Sacrifice at 13.
Their later ranks unlock every three levels, reaching rank five at levels 22 through 25.
Will of Sauron unlocks at levels 16, 18, 20, 22, and 25.
The six ranked second-page passives start at levels 10 through 15, with two levels between ranks.
Master of the Dead, Death from Shadow, and Endless Night unlock at levels 20, 21, and 23.
These requirements apply to learning upgrades; existing purchased ranks are preserved.
