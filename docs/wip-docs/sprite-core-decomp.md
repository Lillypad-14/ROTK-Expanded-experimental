## Matching and readability

sprite_free uses three documented MATCH_PIN declarations and no assembly barriers. All eight subsets of the pins were compiled and compared; only all three together match. The audit is free-pin-audit.txt, generated by minimize_free_pins.py. The macros expand to ordinary C variables with ROTK_MATCH_HACKS=0. The all-dropped variant compiles, with the expected register allocation differences.

sprite_allocOamMatrix uses one matching pin for the active-count address. Removing it was tested and produces an extra live register and eight instruction differences. Other source in this batch matches without pins.

MissionOffsetTable models the relative-offset layout used by mission groups and records. Its offsets array produces the original two-step address calculation. An index-plus-one halfword cast produced different address calculations and omitted the original callee-saved register.

New globals: the 16 OBJ palette reference counts and release timers, the 32 OBJ affine-matrix allocation flags, and the matrix active-range count. Addresses were read from GhidrAssist hexdumps of the literal pools, not inferred from host tooling.
