# gdb-scripts

Shared gdb scripts for mGBA debugging.
Load one on top of the debug bundle: `gdb -x build/debug/rotk.gdb -x gdb-scripts/<name>.gdb`.

- `scenes.gdb`: `warp` to any mission, request any `scene`, trace scene changes.
- `audio.gdb`: play and sweep sound effects and songs to identify ids.
- `heap.gdb`: game heap usage, fragmentation, and integrity; log allocator calls or sample per frame.
- `items.gdb`: `hollow_uniques` fills the hack's Ranger Hollow pages 70-75 with all 53 uniques.

For item testing, build matching ROM and symbols with `make hack debug`, then load `items.gdb` using `build/debug/rotk_hack.gdb`.
Back up your save, close the Hollow, and run `hollow_uniques` in single-player.
It runs `settle`, writes and verifies the six SRAM pages, and leaves the game paused.
Continue and reopen the Hollow to see the items.
Occupied cells are preserved unless you pass `force`.
Forced replacement also clears the final unused cell.
These writes change SRAM immediately, without an in-game save.
Let mGBA flush its save file before copying the test save.

`build/debug/utils.gdb` is generated by `make debug` and sourced by `rotk.gdb` / `rotk_hack.gdb`.
It provides the `settle` command that runs the game to the next main loop tick, which is generally a safe point to call other functions from.

If you want to make your own local uncommitted gdb scripts, put them somewhere in `local`, e.g. `local/gdb-scripts/`.
